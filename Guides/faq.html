Full installation guide Every feature explained

Install steps

You need Windows 10 or 11 (64-bit), American Truck Simulator or Euro Truck Simulator 2 on Steam, your purchase key, and internet to activate. The installation guide shows every step in full.

  1. Double-click Fleet Manager Pro Setup.exe. If Windows shows a blue "Windows protected your PC" box, click More info, then Run anyway.
  2. Accept the licence agreement, click Install, then Finish. No administrator password is needed.
  3. A black window opens: leave it open. Your browser opens http://127.0.0.1:8760. If it doesn't, type that address yourself.
  4. Type your purchase key (FMP-XXXX-XXXX-XXXX-XXXX), tick the licence agreement box and click Activate this PC.
  5. Name your company, create the owner account (password of at least 8 characters) and click Create company.
  6. Close the game. Open Settings > Telemetry and, under Game plugin, click Install next to each game.
  7. Start the game and click OK on the "advanced SDK features" message.
  8. Get into your truck. The top bar of Fleet Manager Pro shows your speed and truck: you're ready to drive.

Were you sent a zip instead? Unzip it to a folder, double-click Fleet Manager Pro.exe in it, and carry on from step 3.

First checks when something is wrong

These fix most problems. Try them in this order.

  1. Is the black window still open? If not, start Fleet Manager Pro again.
  2. Reload the page in your browser, or type http://127.0.0.1:8760.
  3. Close Fleet Manager Pro and the game. Start Fleet Manager Pro first, then the game.
  4. Look at the top bar: it says whether the game is found.
  5. Open Updates and press Check for updates: the problem may already be fixed.
  6. Still wrong? Restart the PC, then look for your problem below.

Fix: installing and starting

"Windows protected your PC"

Windows shows this for new programs that aren't signed yet. Click More info, then Run anyway.

Microsoft Defender (or another antivirus) blocks or removes it

The program isn't code-signed yet, so antivirus programs may wrongly flag it.

  1. Start menu > type Windows Security > Virus & threat protection > Protection history.
  2. Click the entry that names Fleet Manager Pro. Check the path is the file you were sent or your Fleet Manager Pro folder.
  3. Actions > Restore or Allow on device.
  4. If it keeps happening: Manage settings > Add or remove exclusions > Add an exclusion > Folder, and pick only %LOCALAPPDATA%\Programs\Fleet Manager Pro.
  5. Run Fleet Manager Pro Setup.exe again if files are missing. Your data is kept.

Only allow the file you got from the seller. Other antivirus programs have the same options under Quarantine and Exceptions.

It closes straight away, or won't start
  1. Open Task Manager and check it isn't already running.
  2. Check antivirus hasn't removed a file (see above).
  3. Run Fleet Manager Pro Setup.exe again: it puts back missing files and keeps your data.
The black window is open but no page appears

Type http://127.0.0.1:8760 in Edge, Chrome or Firefox. Start with http://, not https://, on the same PC.

"Port 8760 is already in use"

Another copy is running. Close it in Task Manager. Or start on another port: press Windows + R, paste %LOCALAPPDATA%\Programs\Fleet Manager Pro, press Enter, click the address bar, type cmd, press Enter and run:

"Fleet Manager Pro.exe" --port 8770

Fix: activation

"Can't reach the licence server"
  1. Check your internet connection and try again.
  2. Turn off your VPN for a moment.
  3. Allow Fleet Manager Pro in your firewall or antivirus.
  4. Still no? Wait a while and try again, then contact the seller.
"This purchase is already active on 2 PCs"

On a PC you no longer use, open Settings > Licence > Deactivate this PC. If that PC is gone, ask the seller to release it.

"That purchase key doesn't exist"

Check for typing mistakes. Keys start with FMP- and use only letters A-Z and digits 2-7 (no 0, 1, 8 or 9). Keys starting with FM- are for the older app.

It worked before and now asks to be activated

Connect to the internet: without it, Fleet Manager Pro works for 7 days. If you moved the program to another PC, activate there with the same key.

Fix: the game and jobs

The top bar says "waiting for game"
  1. Close the game.
  2. Settings > Telemetry > Game plugin > Install next to your game.
  3. Start the game and click OK on the "advanced SDK features" message.
  4. Get into the truck.

In Settings > Telemetry, the Source must not be set to Demo simulator.

The top bar says "game not running"

The game is closed or still on the profile or menu screen. Load your profile and get into the truck.

My game isn't in the plugin list

In Steam, right-click the game > Manage > Browse local files. Type that folder in the box below the list and click Install here. Or copy plugin\scs-telemetry.dll from the Fleet Manager Pro folder into bin\win_x64\plugins in the game's folder (create plugins if it isn't there).

My delivery wasn't logged
  1. Fleet Manager Pro must be running before you deliver. Start it before you drive.
  2. While driving, Live Cockpit should show "On job".
  3. Missed one? Logbook > Log a job manually. A manager may have to approve it before it's paid.
A delivery says "pending review"

Its pay is being held: the checks found something unusual (for example, the app was closed for most of the drive, or the truck's position jumped). A manager opens the job and clicks Approve & pay or Reject.

The page shows no jobs, or the wrong units

Check the Game box at the top: ATS, ETS2 or Both. Pages show only that game's jobs, in its units.

"Send to game" isn't there, or the contract isn't in the game
  1. Use a browser on the PC where the game is installed.
  2. The contract needs a From city, To city and Cargo picked from the lists.
  3. In the game, load the save named Fleet Manager Pro - Contract #N, then take the job at the pickup company.
  4. It's single-player only; TruckersMP doesn't use your saves.
I can't claim a contract

You may be out of driving hours, or your truck is on a maintenance hold from an inspection defect. Open ELD & Compliance: take a rest (or Simulate rest), and ask a manager to mark the defect repaired.

The in-game overlay doesn't show

Run the game in windowed or borderless mode: exclusive full screen hides other windows. Press Ctrl + I (unless you changed it).

Fix: drivers and other PCs

Other PCs can't open the page
  1. On the main PC, close Fleet Manager Pro and start Fleet Manager Pro (LAN) from the Start menu (zip copy: Start Fleet Manager Pro (LAN).bat).
  2. Allow it if Windows Firewall asks.
  3. On the other PC, type the https:// address the black window shows.
  4. The first time, the browser warns about the certificate: Advanced > Continue. Your own PC made it, and the connection is encrypted.
A driver at home can't connect over the internet

Open Drivers > Connect a driver and work down the steps: LAN mode, your internet address, and opening the port on your router. Your PC must stay on with Fleet Manager Pro in LAN mode while they drive.

A remote driver's jobs don't show up
  1. Their connection window must stay open while they drive.
  2. The game plugin must be installed on their PC.
  3. Make sure they use their own file or command from Connect a driver. If the token was changed, send a new one.
"Too many wrong passwords"

Wait five minutes and try again. A manager can reset a driver's password on the driver's profile page.

I forgot the owner password

Contact the seller. It can't be read back, only reset.

The tablet won't connect

Turn on tablet access on the Tablet page, keep the tablet on the same Wi-Fi as the PC, scan the code, and choose to continue if it warns about the certificate.

Fix: data and updates

A new version asks me to create a company

Nothing is lost: it just found no data next to it. Close it, rename the new data folder to data-empty, copy your real data folder in its place, and start again.

An update won't install
  1. Check your internet connection.
  2. Open Updates, press Check for updates, then Update now.
  3. Stop driving first: automatic updates wait until nobody is driving.
  4. Still no? Close the app and run the newest Setup file the seller sent you. Your data is kept.
I need to go back to a backup
  1. Close Fleet Manager Pro and copy the whole data folder somewhere safe.
  2. In data, rename fleet.db to fleet-old.db, and move fleet.db-wal and fleet.db-shm out of the folder if they are there.
  3. Copy the backup you want from data\backups into data and rename it to fleet.db.
  4. Start the app.
The Global Leaderboard isn't updating

It updates every 10 minutes while the app runs. You can press Update now, but not more than once every 30 seconds. You need internet and an activated copy.

Questions: general

What is Fleet Manager Pro?

A company manager for virtual trucking. It logs your deliveries from the game and runs the rest: drivers, dispatch, trucks, money, driving hours, recruitment, events and leaderboards.

Which games does it work with?

American Truck Simulator and Euro Truck Simulator 2. One company can run both, each with its own units.

How much does it cost?

It's planned as a one-time $10 with every feature and no subscription. It isn't on general sale yet, and the price may change before launch.

Do I need Python, a database or a web server?

No. Everything is in the one Setup file. It runs on your PC and opens in your browser.

Does it work on Mac or Linux?

The program needs Windows 10 or 11. Drivers can open your company in a browser on other devices.

Do I have to enter jobs by hand?

No. Deliveries log themselves. You can still add one by hand.

Does it change my game or my saves?

The plugin only reads data. Send to game makes a new save and never changes your others.

Does it work with TruckersMP?

Deliveries log from the game's telemetry, and you can share your Apply link with TruckersMP drivers. Send to game is single-player only.

Can I use other telemetry programs at the same time?

Yes. Several programs can use the same plugin at once.

Can I try it without the game?

Yes: Settings > Telemetry > Source > Demo simulator drives a truck for you. Its jobs and money go into your real logbook, so use it before you start your company properly. They don't count on the Global Leaderboard.

Questions: data and updates

Where is my data?

In one folder named data, next to Fleet Manager Pro.exe. If you used Setup, press Windows + R and paste:

%LOCALAPPDATA%\Programs\Fleet Manager Pro\data
How do I update?

An Owner or Manager opens Updates, presses Check for updates, then Update now. The app closes and reopens by itself and your data isn't touched.

How do I move from the zip version to the installed version?
  1. Close the old copy.
  2. Run Setup, and untick Start Fleet Manager Pro at the end.
  3. Copy the data folder from your old folder into %LOCALAPPDATA%\Programs\Fleet Manager Pro.
  4. Start it from the Start menu and check your company is there.
How do I move to another PC?
  1. Old PC: Settings > Licence > Deactivate this PC, then close the app.
  2. Copy the whole data folder to the new PC.
  3. Run Setup on the new PC without starting the app, and put data next to Fleet Manager Pro.exe.
  4. Start it, activate with the same key, and install the game plugin.
How do I back up?

Close the app and copy the data folder. While it's running, System & Backups > Back up now saves the company database. It also makes one each day and keeps the newest 14.

Does uninstalling delete my company?

No. The data folder stays until you delete it yourself.

Questions: your key

How many PCs can I use?

Two. Deactivate one to move to another.

Do my drivers need a key?

No. Only the main PC is activated.

Does it work offline?

You need internet to activate. After that it works for 7 days without it.

Can I share my copy?

No. Each copy is made for one purchase key and is licensed to you. Keep your key private.

Questions: drivers

How do I add a driver?

Drivers > Add member. Or share your Apply link from Recruitment and accept applications there; the link works even when your PC is off.

How does a driver connect from their own PC?
  1. They install Fleet Manager Pro with the same Setup file and install the game plugin on their PC.
  2. You open Drivers > Connect a driver, pick them and press Download file. Send it only to that driver: it holds their private token.
  3. They put the file in their Fleet Manager Pro folder, double-click it and leave it open while they drive.
What can each role do?
  • Owner: everything.
  • Manager: fleet, finance, members and settings.
  • Dispatcher: contracts, events and announcements.
  • Driver and Trainee: drive, claim contracts and sign up for events.
What happens when I fire a driver?

Their account is deleted. Their deliveries and pay stay in the books as "Former driver".

Questions: running the company

How much money does a company start with?

$300,000. It's the same for every company.

How do contracts work?

A dispatcher posts one on Dispatch, a driver claims it, and a matching delivery completes it by itself.

Should I buy or lease?

Buying takes all the money now. Leasing takes a small down payment and a weekly payment; at the end you buy, return or renew. Truck leases include a set number of miles; trailer leases have no mileage limit.

What are Hours of Service and DVIRs?

Driving-time rules and vehicle inspections, on in-game time. US rules for ATS, EU rules for ETS2. Change the rules or turn parts off in Settings > Compliance.

Where do I change pay, fuel and repair prices?

Settings > Economy.

Can it post to Discord?

Yes. Add a webhook in Settings > Discord.

Can I show it on stream?

Yes. Make a stream overlay, copy its link into an OBS Browser source, and keep that link private.

Questions: privacy

What leaves my PC?

Your company database stays on your PC. These do go to the licence server:

  • Licence checks: your key and an ID for your PC.
  • Recruitment: your company name, Apply page text and whether applications are open. Applications wait there until your copy collects them.
  • Global Leaderboard: your company name, currency and totals, including revenue, unless you leave it. Driver names are off unless you turn them on.

If you add a Discord webhook, those posts go to Discord.

How do I leave the Global Leaderboard?

Open Leaderboard > Global and turn your company off. It's removed from the server straight away. You can still look at the board.

Are the Global Leaderboard numbers checked?

Each company's copy reports its own totals, so treat it as friendly competition.

Can people on the internet reach my PC?

Not unless you allow it. By default only your own PC can open it. LAN mode opens it to your network, encrypted, and only opening a port on your router lets the internet in.

Still stuck?

Contact the person you bought Fleet Manager Pro from. Include:

  • your version (shown on the Updates page),
  • what you were doing and the exact message,
  • a screenshot,
  • the log from System & Backups > Logs.

Never send your password, your data folder, a driver's token or connection file, or post your purchase key in public.
