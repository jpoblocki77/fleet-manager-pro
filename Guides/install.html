What you need

You get one file: Fleet Manager Pro Setup.exe. Nothing else needs installing: no Python, no database.

1. Install

  1. Double-click Fleet Manager Pro Setup.exe.
  2. Accept the licence agreement, choose whether you want a desktop shortcut, and click Install. Windows does not ask for an administrator password.
  3. Leave Start Fleet Manager Pro ticked and click Finish. Later, start it from the Start menu or the desktop shortcut.
  4. A black window opens (leave it open while you use the app) and your browser opens http://127.0.0.1:8760. If the browser does not open, type that address yourself.

Windows protected your PC? The first time, Windows may show a blue box because the program is new. Click More info, then Run anyway.

If Microsoft Defender blocks or removes Fleet Manager Pro

This is a temporary step. Fleet Manager Pro is new and is not yet code-signed, so Microsoft Defender may wrongly report Fleet Manager Pro Setup.exe or the installed program as a threat (a "false positive"). The program is being submitted to Microsoft to be signed and cleared; once that is done these steps won't be needed.

  1. Open Windows Security (Start menu > type Windows Security) > Virus & threat protection > Protection history.
  2. Click the entry that names Fleet Manager Pro. Check the path shown is the Setup file you were sent, or AppData\Local\Programs\Fleet Manager Pro.
  3. Click Actions > Restore (if it was quarantined) or Allow on device (if it was blocked). Click Yes if Windows asks for permission.
  4. To stop it being flagged again: Virus & threat protection settings > Manage settings > scroll to Exclusions > Add or remove exclusions > Add an exclusion > Folder, and pick %LOCALAPPDATA%\Programs\Fleet Manager Pro (only that folder).
  5. Start Fleet Manager Pro again. If it still does not start, run Fleet Manager Pro Setup.exe again.

Only do this for the Fleet Manager Pro folder you were given, never for other programs or whole drives. When you install a signed version later, remove the exclusion again (same place, click it > Remove). Other antivirus programs (Norton, Avast, Bitdefender...) have the same options under Quarantine and Exceptions. If it keeps happening, contact whoever gave you your licence key.

2. Activate

  1. On the Activate screen, type your licence key, tick I have read and agree to the licence agreement (the link opens it) and click Activate this PC.
  2. That is it. The key is remembered; you will not be asked again on this PC.

3. Create your company

  1. Enter your company name, tag and motto, pick your main game and units. Every company starts with $300,000 capital (fixed).
  2. Create the owner account: a username and a password of at least 8 characters. Keep this password safe: the owner is the only account that can do everything.
  3. Click Create company. You are signed in and see the Dashboard.

4. Install the game plugin

Fleet Manager Pro reads the game through a small plugin, scs-telemetry.dll (included). It goes in the game's plugins folder.

The easy way

  1. Close the game if it is running.
  2. In Fleet Manager Pro go to Settings > Telemetry. Under Game plugin your games are listed.
  3. Click Install next to each game. (If your game is not listed, type its folder in the box below the list and click Install here.)
  4. Start the game. It shows a message about advanced SDK features: click OK.

By hand

Copy %LOCALAPPDATA%\Programs\Fleet Manager Pro\plugin\scs-telemetry.dll into:

...\Steam\steamapps\common\American Truck Simulator\bin\win_x64\plugins\
...\Steam\steamapps\common\Euro Truck Simulator 2\bin\win_x64\plugins\

Create the plugins folder if it does not exist. To find the game folder: in Steam, right-click the game > Manage > Browse local files.

Check it works: with the game running and your truck on the road, the top bar of Fleet Manager Pro shows your speed and truck, and Live Cockpit shows the gauges.

5. Your first delivery

  1. Pick your game in the Game box at the top (ATS, ETS2 or Both). Pages then show that game's data in its units.
  2. Open ELD & Compliance > DVIR inspections, tick the eight items and submit a pre-trip report. (Picking up a load without one is a small fine.)
  3. Take any job in the game and deliver it. Leave Fleet Manager Pro running while you drive.
  4. When you deliver, the job appears in the Logbook with its route, score, pay and XP, and the money is in Finance.

No game to hand? Settings > Telemetry > Source > Demo simulator drives a truck for you so you can look around.

6. More drivers (optional)

On the same network

  1. On the PC that runs Fleet Manager Pro, open Drivers > Connect a driver and press Let other PCs in (once). The page shows an address like https://192.168.1.20:8760. Allow it if Windows Firewall asks.
  2. Other PCs open that address in a browser. The first time, the browser warns about the certificate (it is made by your own PC): choose Advanced > Continue. The connection is encrypted.
  3. A manager adds each driver under Drivers > Add member, or drivers apply on your online Apply link (section 8) and a manager accepts them.

Logging a driver's own game

Each driver who plays on their own PC installs Fleet Manager Pro on that PC with the same Setup file and runs one command. The exact command, with that driver's token and your server's fingerprint, is on their profile page under Remote telemetry:

"Fleet Manager Pro.exe" agent --server https://HOST-PC:8760 --token TOKEN --pin FINGERPRINT

Press Windows + R, type %LOCALAPPDATA%\Programs\Fleet Manager Pro and press Enter. Click the folder's address bar, type cmd, press Enter and paste the command.

They do not need their own licence key for this: only the main PC is activated.

8. Recruit drivers

Drivers apply to your company on your own online Apply page. It is hosted for you, so there is nothing to set up and no router or firewall to change, and it works even while your PC is off.

  1. Open Recruitment (Company menu). A few minutes after activation your link appears under Your Apply link, for example http://fleetmanager.servehttp.com:8750/apply/k7m2p9qa. Each company gets its own link.
  2. Click Copy and share the link on your Discord, TruckersMP page, website or socials.
  3. Drivers open it on any device and fill in their name, how to contact them (Discord or email), age, country, game, experience and a message.
  4. Fleet Manager Pro collects new applications about every 10 minutes while it runs (or press Check now). They appear on Recruitment marked online; Owners and Managers get a notification, and so does your Discord channel if a webhook is set in Settings.
  5. Choose Accept (creates the driver's account, optionally in a division - then send them their username and password), Interview or Reject. Internal notes stay with the application.

Your page shows your company name and the text from Settings > Recruitment. Untick Accept applications there to close the page; tick it again to reopen it.

Privacy and limits. Applications wait on the licence server only until your copy collects them, then they are deleted there. Only your activated copy can collect your applications. To stop spam, each person can send at most 5 applications an hour, bots are filtered out, and at most 300 applications can wait at once - so open Fleet Manager Pro regularly.

No link, or "Last check failed"? The PC needs internet access and an activated copy. Press Check now; if it still fails, contact whoever gave you your licence key.

9. Lease trucks

Instead of paying for a truck all at once, the company can lease it: a small down payment, then a fixed weekly payment for a set number of weeks with a set number of miles included.

  1. Open Truck Leasing (Company menu).
  2. Under Compare lease plans pick a new truck from the dealer list (or one of your own trucks) - the price fills in.
  3. Every plan is shown side by side: length, miles included, interest rate, down payment, weekly payment (truck value used plus interest), total you pay, total interest, the price to buy it at the end, the extra-mile charge and the fee for ending early.
  4. Click Lease on ... under the plan you want and confirm. The down payment is taken now; the weekly payment comes out of the company account every week.
  5. Open the lease (click it in Your leases) to see miles used, the pace you're on, payments made and what buying or returning the truck would cost today.
  6. When the last payment is made you're notified: Buy it for its end value, Return it (extra miles are charged) or Renew on any plan.

Everyone in the company can see the costs; only Owners and Managers can lease, end a lease or change plans (Lease plans > Edit / New plan). Changing a plan never changes leases already signed. A leased truck can't be sold - buy it out first.

10. Looking after your data

  • Everything (company, drivers, jobs, money, licence) is in %LOCALAPPDATA%\Programs\Fleet Manager Pro\data (press Windows + R and paste that to open it). It appears the first time you start the program.
  • Back up: close Fleet Manager Pro and copy the data folder somewhere safe.
  • Move to another PC: in Settings > Licence click Deactivate this PC, run Fleet Manager Pro Setup.exe on the new PC, copy the data folder into the same place there, start it and activate with the same key.
  • Already using a copy from a zip? Close it, install, then copy its data folder into %LOCALAPPDATA%\Programs\Fleet Manager Pro before starting the installed one.
  • Update to a new version: open Updates, press Check for updates, then Update now. The app closes and reopens by itself and your data is not touched.
  • Update by hand (if you are sent a new Setup file): close Fleet Manager Pro and run it. Your data is kept.
  • Step by step: READ ME - Your Data.txt, in the program folder and the Start menu, covers moving your data, backing up and going back to a backup.
  • Uninstall: Windows Settings > Apps. Your data folder stays; delete it yourself if you no longer want it.

Troubleshooting

Top bar says "game not running"The game is closed or still on the profile/menu screen. Get into the truck.
Jobs are not loggedFleet Manager Pro must be running before you deliver. Check Live Cockpit shows "On job" while you drive.

Good to know

  • The game plugin scs-telemetry.dll is open-source (MIT licence). It only reads data; it does not change your game or your save.
  • It works alongside other telemetry tools: several can use the same plugin at once.
  • Fleet Manager Pro only listens on your own PC unless you let other PCs or tablets in.
