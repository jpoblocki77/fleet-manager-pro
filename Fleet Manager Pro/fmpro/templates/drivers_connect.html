What the driver does

  1. Install Fleet Manager Pro on their PC with your Setup file, or copy the Fleet Manager Pro folder there. No purchase key is needed to send their game.
  2. Install the game plugin: copy plugin\scs-telemetry.dll into <game folder>\bin\win_x64\plugins\.
  3. Put the downloaded file into that Fleet Manager Pro folder and double-click it (or run the line above there). Leave its window open.
  4. Start the game and drive. Jobs show up here under {{ pick.display_name }}.

The line contains {{ pick.display_name }}'s private token: send it only to them. If it leaks, press New token on their profile and send the new one.
