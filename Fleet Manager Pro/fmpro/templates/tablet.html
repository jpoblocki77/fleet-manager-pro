How to connect

  1. Put the tablet on the same Wi-Fi as this PC.
  2. Open the Camera app and point it at the code. Tap the link that appears.
  3. The first time, the browser warns that the connection isn't private. That's expected: this PC makes its own certificate.
    • iPad / iPhone (Safari): tap Show Details, then visit this website, then Visit Website.
    • Android (Chrome): tap Advanced, then Proceed to {{ ip }} (unsafe).
  4. You're in. To open it like an app next time: Share → Add to Home Screen (iPad) or ⋮ → Add to Home screen (Android).
