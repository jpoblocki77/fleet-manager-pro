Send contract to the game

Fleet Manager Pro copies the save you pick into a new save slot named "Fleet Manager Pro - Contract #…" with this job added to the pickup company's freight market. The save you pick, and all your other saves, are not changed.

  1. Save your game first (or use the latest autosave), then click Send.
  2. In the game: Load game → pick Fleet Manager Pro - Contract #….
  3. Drive to the pickup company and take the job from its freight market. Delivering it completes the contract.
  4. The job stays in the freight market for about a game day, the same as the game's own jobs.

Single-player only (TruckersMP doesn't use your saves). If the game is open, load the new save from its menu.
